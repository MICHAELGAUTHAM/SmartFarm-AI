B2B API Documentation

Integrate our intelligence algorithms directly inside your own application.

Authentication

All Enterprise requests must include a Bearer API Token inside the headers.

Authorization: Bearer sk_smartfarm_your_secret_key

Endpoints

POST /api/v1/predict

Analyzes localized constraints fetching live weather/market thresholds dynamically to return aggregated farming intelligence logic.

Parameters (JSON):
  • income (integer) - Estimated Baseline Income
  • expenses (integer) - Operational Expenditure
  • city (string) - Geographic fetch point
Response Structure: 
{
  "status": "success",
  "data": {
    "profit": 35000,
    "risk_score": 25.5,
    "explanation": "Stable market patterns.",
    "recommendation": "Standard schedules mapped."
  },
  "timestamp": "2026-04-26T00:00:00Z"
}

GET /api/v1/export

Extracts deep User Prediction timelines into strict CSV string outputs for enterprise modeling.

POST /api/v1/feedback

Allows enterprise API consumers or standard web interactions to pipe feedback variables to admin algorithms natively.
